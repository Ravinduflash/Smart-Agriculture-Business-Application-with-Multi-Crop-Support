### 🎯 How to Use

#### **For Users:**
1. **Click the chatbot icon** (bottom-right green button)
2. **Ask questions** like:
   - "How do I add a new crop?"
   - "Why are my sensors showing N/A?"
   - "How to check soil moisture levels?"
   - "Where can I find analytics?"
3. **Use quick actions** for instant help
4. **Follow related topics** for deeper assistance

#### **For Administrators:**
1. **Press `Ctrl+Shift+T`** to open Training Manager
2. **Add new questions** as users ask them
3. **Edit existing answers** to keep them current
4. **Export knowledge** for backup/sharing
5. **Monitor usage** and improve responses
